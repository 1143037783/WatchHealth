# WatchHealth

基于 Apple Watch 健康数据的个人健康查询技能，适用于 [OpenClaw](https://github.com/openclaw/openclaw) 平台。

## 功能

目前检测的健康数据类型：

| 指标 | 说明 |
|------|------|
| 步数 | 总步数、活动分钟、峰值步数、最长久坐 |
| 活动能量 | 每日活动消耗的卡路里 |
| 静息心率 | 安静状态下的心率 |
| 心率变异性 | HRV，反映自主神经系统状态 |
| 最大摄氧量 | VO₂ max，有氧耐力指标 |
| 呼吸频率 | 每分钟呼吸次数 |
| 手腕温度 | 睡眠期间手腕温度 |
| 睡眠分析 | 睡眠时长、各阶段分布 |

- 支持多设备数据去重

## 数据结构

健康数据存放在 `~/.openclaw/personal-health-data/`，按日期存储为 JSON 文件，格式：

```json
{
  "metrics": [
    {
      "name": "step_count",
      "units": "count",
      "data": [
        {
          "date": "2026-05-05 08:30:00 +0800",
          "qty": 120,
          "source": "Apple Watch"
        }
      ]
    },
    {
      "name": "resting_heart_rate",
      "units": "bpm",
      "data": [
        {
          "date": "2026-05-05 07:00:00 +0800",
          "qty": 62,
          "source": "Apple Watch"
        }
      ]
    }
  ]
}
```

## 数据统计方案

每种指标的分析策略：

| 指标 | 聚合方式 | 统计指标 | 备注 |
|------|---------|---------|------|
| 步数 | 分钟级差分去重 → 日汇总 | 总步数、活动分钟、峰值步数、最长久坐 | 累计值需差分 |
| 活动能量 | 日汇总 | 总值 (kcal) | 累计值，取当日最终值 |
| 静息心率 | 日统计 | 最低/最高/平均值 (bpm) | 取安静状态采样值 |
| 心率变异性 | 日统计 | 最低/最高/平均值 (ms)、SDNN | SDNN 反映自主神经调节能力 |
| 最大摄氧量 | 日取值 | 当日值 (mL/kg/min) | 通常每日仅 1-2 条记录，趋势比单点重要 |
| 呼吸频率 | 日统计 | 最低/最高/平均值 (次/分) | 睡眠期间采样为主 |
| 手腕温度 | 基线偏离 | 夜间均值 vs 历史基线 (°C) | 相对变化比绝对值更有意义 |
| 睡眠分析 | 日统计 | 总时长、深睡/浅睡/REM 占比 | 按睡眠阶段分类汇总 |

## 使用

在聊天中输入触发词即可查询，例如：

- "我今天走了多少步"
- "我的健康数据"
- "分析我的体检报告"
